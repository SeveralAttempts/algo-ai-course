# Профиль обучения

- Основной язык: C#.
- Опыт: коммерческая разработка; конкретный алгоритмический уровень не предполагается.
- Режим: без фиксированного расписания; типичная сессия 2–3 часа, можно остановиться раньше.
- Предпочтение: глубокое понимание, самостоятельный вывод и инженерная проверка вместо поверхностного запоминания.
- Цель: профессиональное владение алгоритмами и структурами данных.
- Траектория: классическое ядро перед специализациями, если направление явно не изменено.
- Переносимость: состояние полностью восстанавливается из репозитория; команда продолжения — «Давай продолжим».
- Практика: C#, автоматические тесты, доказательства, анализ сложности, code review и benchmarks.
- Неизвестно до диагностики: интересующие специализации, опыт соревнований, глубина дискретной математики и уровень по отдельным алгоритмическим областям.
