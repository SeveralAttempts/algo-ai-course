## Главный блокирующий дефект

Условие относится к минимуму и максимуму **всего непрерывного подмассива**. Реализация на строках 35 и 41 проверяет только соседние пары:

```csharp
Math.Abs(values[i + 1] - values[i]) <= maxDifference
```

Из допустимости каждой соседней пары не следует допустимость всего сегмента.

Минимальный контрпример:

```text
values = [1, 2, 3], maxDifference = 1
```

Обе соседние разности равны 1, но для всего массива `max - min = 3 - 1 = 2`. Правильный результат — `(0, 2)`, а текущая реализация возвращает `(0, 3)`.

## Ошибочные ожидания существующих тестов

- `[1,2,3,4,5]`, limit 1: ожидается `(0,2)`, не `(0,5)`.
- `[8,2,10]`, limit 1: одиночный элемент всегда допустим, поэтому `(0,1)`, не `(0,0)`.
- `[16,200,83,7,14,21]`, limit 7: `[7,14,21]` имеет диапазон 14; результат `(3,2)`.
- `[7,2,-3,2,17]`, limit 5: допустим `[2,-3,2]`, результат `(1,3)`, не `(0,4)`.
- Тесты с последовательностями `[5,14,23]` аналогично принимают цепочку соседних разностей за диапазон всего сегмента.

## Вторичные дефекты, к которым вернёмся после исправления модели

- Для одного элемента и при отсутствии допустимой пары должен возвращаться первый singleton `(0,1)`.
- `values.Any()` вызывается до проверки `values == null`.
- Overflow-sensitive тест из задания отсутствует; `values[i + 1] - values[i]` выполняется в `int`.
- Словарь по значению элемента не допускает два сегмента с одинаковым начальным значением.
- При равной длине выбирается минимальный ключ-значение, хотя контракт требует минимальный индекс `Start`.
- `System.Reflection` и `System.Reflection.Emit` не используются.

Эти пункты пока не исправляет наставник: следующая попытка начинается с корректного тестового контракта.

## Следующая самостоятельная правка

Не менять реализацию. Сначала исправить ожидания существующих тестов по правилу `max(segment) - min(segment) <= maxDifference` и добавить контрпример `[1,2,3], 1 -> (0,2)`. После этого запустить `dotnet test`: новые падения должны показать, что тесты теперь действительно ловят основной дефект алгоритма.
