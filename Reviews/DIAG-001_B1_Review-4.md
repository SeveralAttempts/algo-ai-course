# Review — DIAG-001 B1, набросок SortedSet

Дата: 2026-07-24.

## Что выбрано правильно

- `SortedSet<(int Value, int Idx)>` сохраняет порядок по значению и делает дубликаты уникальными за счёт индекса.
- `Add` и `Remove` пары выполняются за `O(log n)`.
- Такой набор операций позволяет построить требуемое решение `O(n log n)`.

## Проверка

- Solution собирается без предупреждений и ошибок.
- Тесты: 3 failed, 9 passed во всём solution.
- Падают `HasSegmentWithNegativeValues`, `MoreThanOneSegment`, `TwoEqualSegmentsInARow`.

## [P1] SortedSet содержит весь массив, а не текущее окно

Строки 30–33 заранее добавляют все элементы. После этого структура знает порядок значений, но больше не моделирует непрерывный сегмент `[left..right]`. Для движущегося окна требуется добавлять `(values[right], right)` при сдвиге `right` и удалять ровно `(values[left], left)` при сдвиге `left`.

Минимальный контрпример: `[2,1,2]`, limit 1. Весь массив допустим и ответ `(0,3)`, но минимальное значение находится по индексу 1. Индекс min/max-значения не является границей окна.

## [P1] Возвращаемые индексы выводятся из позиций min/max

Строка 48 использует `dict.First().Idx` и разность индексов min/max. Границы результата — отдельные `left/right`; min/max нужны только для проверки допустимости. Экстремальные значения могут находиться где угодно внутри окна.

## [P2] Стоимости крайних элементов и LINQ

- Для .NET `SortedSet<T>` свойства `Min`/`Max` проходят путь по сбалансированному дереву, поэтому оценка — `O(log n)`, а не `O(1)`.
- Текущие `First()`/`Last()` — LINQ-операторы, не свойства `SortedSet.Min/Max`; особенно `Last()` может перечислить весь набор.
- `ElementAt(count)` для `SortedSet` не является индексным доступом и стоит `O(n)`.

Даже с `Min/Max = O(log n)` итог остаётся `O(n log n)`, потому что границы суммарно двигаются `O(n)` раз.

## [P3] Порядок аргументов Assert.Equal

В xUnit сначала передаётся expected, затем actual. Текущие тесты используют обратный порядок: `Assert.Equal(maxmin, (...))`; это не меняет факт равенства, но делает сообщения об ошибках вводящими в заблуждение.

## Следующее действие

Код пока не менять. Вручную протрассировать `[8,2,4,7]`, limit 4 таблицей: `right`, добавленная пара, содержимое SortedSet, min/max, удалённые слева пары, новый `left`, лучший `(Start,Length)`. Структура должна содержать только пары текущего окна.
