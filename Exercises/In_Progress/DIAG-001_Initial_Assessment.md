### A5. Трассировка

Для массива `[1, 3, 3, 3, 8]` вручную протрассируйте код. Какие `left`, `right`, `mid` получаются и что возвращается?

```csharp
static int Find(int[] a, int x)
{
    int left = 0, right = a.Length;
    while (left < right)
    {
        int mid = left + (right - left) / 2;
        if (a[mid] < x) left = mid + 1;
        else right = mid;
    }
    return left;
}
```

Объясните назначение функции для произвольного `x`, включая отсутствующий.

## Часть B — практическая (60–90 минут, после разбора A)

### B1. Реализация и тесты

Реализуйте на C# метод:

```csharp
public static (int Start, int Length) LongestStableSegment(
    IReadOnlyList<int> values,
    int maxDifference)
```

Он возвращает самый длинный непрерывный сегмент, в котором `max - min <= maxDifference`. При равной длине выбрать сегмент с меньшим `Start`. Для пустого списка вернуть `(0, 0)`. `values == null` и `maxDifference < 0` должны приводить к `ArgumentOutOfRangeException`/`ArgumentNullException` согласно выбранному ясному контракту.

Примеры:

- `[8, 2, 4, 7]`, `4` → `(1, 2)`;
- `[10, 1, 2, 4, 7, 2]`, `5` → `(1, 5)`;
- `[4, 4, 4]`, `0` → `(0, 3)`.

Ограничения: до 200 000 элементов; значения — любые `int`; ожидаемое время `O(n log n)` или лучше, дополнительная память `O(n)` или меньше. Не используйте сортировку всего ввода. Сначала напишите 6+ тестов, включая overflow-sensitive случай. Разместите код в `src/Algorithms/Diagnostics` и тесты в `tests/Algorithms.Tests/Diagnostics`.
